### Scope and Usage
  
The Genomic Data File profile is used to represent a genomic data file as a DocumentReference resource. It provides a standardized mechanism for communicating the availability of a file and the information required to retrieve and appropriately interpret its contents. This profile is intended for files that contain genomic data generated or used in the course of genomic testing, including, for example, sequence alignment files, variant call files, and other files supporting genomic analysis, interpretation, or reporting. The file itself may be made available through the DocumentReference.content.attachment element, using an accessible URL or other attachment representation as appropriate to the implementation.

This profile is used when genomic data must be exchanged, discovered, or referenced independently of a genomic report while retaining its relationship to the associated clinical and laboratory context. The `DocumentReference.description` element may be used to provide human-readable information about how the file was generated, such as the sequencing method, analysis pipeline, reference sequence build, or other relevant processing details. The profile may also reference related genomic report resources through `DocumentReference.context.related`, enabling consumers to associate the genomic data file with the report(s) for which it was generated, analyzed, or made available. The profile is not intended to encode the genomic observations or interpretations contained in the file; those data are represented using the applicable genomic reporting profiles or are retained in the referenced file.

The `DocumentReference.context.related` element may additionally be used to reference one or more related Specimen resources. This enables a direct, computable association between a genomic data file and the source specimen(s), or other specimens relevant to the generation or interpretation of the file. Referencing specimens in the document context supports traceability across the genomic testing workflow, including circumstances in which multiple specimens contribute to a file or when a file is derived from a specimen distinct from the specimen associated with a related genomic report.
